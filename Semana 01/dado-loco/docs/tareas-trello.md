# Tablero Trello — Dado Loco

Crea un tablero con estas 4 listas (son los estados que pide la actividad):

1. **Iniciado**
2. **Proceso**
3. **No terminado por dificultades**
4. **Terminado**

Crea una tarjeta por cada tarea de abajo y muévela a la lista que corresponda según tu avance real. Comparte el tablero con tu docente (botón *Compartir* → correo del docente).

## Tareas

| # | Tarea | Descripción |
|---|---|---|
| 1 | Análisis del requerimiento | Leer instrucciones y pauta; listar lo que pide el cliente |
| 2 | Definir nombre de la PYME | Elegir el nombre (Dado Loco) |
| 3 | Definir categorías y juegos | 4 categorías, 3 juegos cada una, con precio y descuento |
| 4 | Crear repositorio Git | `git init`, primer commit y subir a GitHub |
| 5 | Estructura de carpetas | `css/`, `img/` y archivos HTML |
| 6 | Conseguir imágenes | Imagen por categoría y por juego |
| 7 | Página principal (`index.html`) | Nombre, listado de categorías con imagen e hipervínculo |
| 8 | Página Estrategia | Fichas de 3 juegos |
| 9 | Página Familiares | Fichas de 3 juegos |
| 10 | Página Cartas | Fichas de 3 juegos |
| 11 | Página Cooperativos | Fichas de 3 juegos |
| 12 | Navegación entre páginas | Menú, anterior/siguiente y volver al inicio |
| 13 | Variables CSS | Colores, sombras, espacios en `:root` |
| 14 | Diseño y posicionamiento | Grid y Flexbox para tarjetas y encabezado |
| 15 | Animaciones CSS (mín. 4) | aparecer, girar, flotar, latido, fondo animado |
| 16 | Responsividad con media queries | Tablet (992px) y celular (600px) |
| 17 | Pruebas en navegador | Revisar links, imágenes y vista en celular |
| 18 | README del proyecto | Explicar estructura y requisitos cubiertos |
| 19 | Entrega | ZIP del proyecto + links de Git y Trello en el AVA |
